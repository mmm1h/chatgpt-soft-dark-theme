## 🛠️ V3.3.0 核心黑科技

*   **全场景智能浮动控制面板 (Switcher Panel)**：
    *   不论白天还是夜晚，右下角始终常驻高保真**磨砂玻璃态（Glassmorphism）**眼科面板。
    *   **动态卡片自适应**：面板会智能识别当前网页的主题。
        *   在**明亮模式**下打开，自动呈现 8 款**日间纸张/自然防护色系**。
        *   在**暗黑模式**下打开，自动呈现 8 款**夜间深色/视网膜防护色系**。
*   **行内代码全主题动态同步 (Dynamic Inline Code Styling)**：
    *   突破性地重构了 inline `code`（行内代码，如 `hexyard-postgres` 等）的 CSS 编译策略，剥离了失效 of `:not(pre code)` 伪类语法，通过全兼容的“全局 code 拦截 + pre code 重置”高级技巧，确保行内代码在任何自定义浅色/深色主题下均能获得完美的色彩重塑。
*   **字体色彩深度关联 (Text Color Harmony)**：
    *   彻底颠覆只改背景的常规操作，每一套配色都配备了由脚本注入的**深度定制字体主次颜色**（如古铜咖、森林绿、亚麻色等）。极大地避免了由于背景改变但字体仍为高对比度纯白/纯黑而引起的眼部聚焦疲劳！
*   **完美的代码块渲染**：
    *   利用 `:has(.cm-editor) > div` 锁定器和透明 `pre` 标签剥离技术，确保代码块无溢出、无黑色直角、无双重边框、文字无截断，并带有 24px 极致圆润边缘！
*   **零能耗与零延迟注入**：
    *   基于 `MutationObserver` 的三维属性（`class`、`data-theme`、`data-oled`）监听，在 1ms 内完成日夜动态状态重载，零闪烁。

## 🛠️ 安装使用指南

### 第一步：安装油猴浏览器插件 (若已安装可跳过)
如果您还没有安装油猴插件，请前往对应浏览器的扩展商店安装：
*   **Chrome 浏览器**：搜索并安装 `Tampermonkey`
*   **Edge 浏览器**：搜索并安装 `Tampermonkey`
*   **Firefox 浏览器**：搜索并安装 `Tampermonkey`

### 第二步：添加本脚本
1. 点击浏览器右上角的 **Tampermonkey 图标**，选择 **“添加新脚本”** (Create a new script)。
2. 清空编辑器中默认生成的模板代码。
3. 打开本地项目文件 [chatgpt_soft_dark_theme.user.js](file:///C:/Users/12562/.gemini/antigravity/scratch/chatgpt-soft-dark-theme/chatgpt_soft_dark_theme.user.js)，复制其全部内容。
4. 将复制的内容粘贴到油猴编辑器的代码框中。
5. 按下快捷键 `Ctrl + S` 保存脚本（或者点击编辑器左上角的 `文件` -> `保存`）。

### 第三步：体验全新护眼界面
*   打开或刷新您的 [ChatGPT 官网](https://chatgpt.com)。
*   **直接点击右下角极具科技感的“小眼睛”悬浮按钮，尽情开启并定制您在明亮/暗黑模式下的专属医学级健康护眼色彩方案！** 🥤
